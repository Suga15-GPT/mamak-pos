# review-notes

This branch holds **no code**. It is the hand-off between the people working on
mamak-pos:

- **`REVIEWER.md`** — standing rules for the reviewer ("R"). Read it every time.
- **`requests/`** — one file per review round, written by the author: what to
  check, at which commit.
- **`reports/`** — one file per round, written by the reviewer: findings and a
  verdict. The author reads these from GitHub instead of having them pasted.

Code lives on `main` and on feature branches. Nothing on this branch is ever
merged into them.
